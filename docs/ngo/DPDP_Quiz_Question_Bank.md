### Q1. Which of the following is an example of personal data under DPDP?

- Module: Module 1
- Topic: What is personal data
- Options:
  - A. A district-level TB case count with no beneficiary names
  - B. A list of village names in a program coverage report
  - C. A pregnant woman's name, age, and mobile number
  - D. The total number of health camps held this quarter
- Correct answer: C. A pregnant woman's name, age, and mobile number
- Guidance / explanation: Personal data is any information that can identify a person directly or in combination. A name, age, and phone number clearly identifies an individual. Aggregated counts and village names alone do not identify anyone.

### Q2. At the organisation, who is the Data Fiduciary under DPDP?

- Module: Module 1
- Topic: Key roles
- Options:
  - A. The beneficiary whose personal data is collected
  - B. The organisation that determines the purpose and means of processing
  - C. The Data Protection Board of India (DPBI)
  - D. The software vendor building the programme MIS
- Correct answer: B. The organisation that determines the purpose and means of processing
- Guidance / explanation: The Data Fiduciary is the organisation that decides what data to collect and why. That is the organisation. The beneficiary is the Data Principal. A software vendor working on the organisation's behalf is a Data Processor.

### Q3. A field coordinator asks a beneficiary to sign a consent form without explaining what data is being collected or why. Is this valid consent?

- Module: Module 2
- Topic: Valid consent
- Options:
  - A. Yes - the signature makes it legally valid
  - B. Yes - as long as the data is used only for the program
  - C. No - valid consent requires the person to be informed
  - D. It depends on the type of data being collected
- Correct answer: C. No - valid consent requires the person to be informed
- Guidance / explanation: Valid consent under DPDP must be free, specific, informed, and unconditional. Signing without explanation does not meet the informed-consent standard.

### Q4. A health outreach worker at a government NHM health camp needs to enter a patient's data into the government HMIS. Does she need a separate DPDP consent form from the patient?

- Module: Module 2
- Topic: Legitimate uses
- Options:
  - A. Yes - any data collection always requires a DPDP consent form
  - B. No - processing for government welfare programs is a legitimate use under Section 7
  - C. Only if the patient is below 18 years old
  - D. Yes, but the form can be collected within 7 days
- Correct answer: B. No - processing for government welfare programs is a legitimate use under Section 7
- Guidance / explanation: Section 7 recognises processing for government welfare programs as a legitimate use, so a separate consent form is not required. Security safeguards and rights handling still apply.

### Q5. A beneficiary tells a field coordinator: 'I want to see what information you have written about me.' What should the field worker do?

- Module: Module 3
- Topic: Rights in the field
- Options:
  - A. Tell the beneficiary that records are confidential and cannot be shared
  - B. Show the beneficiary their complete file immediately
  - C. Note the request with date and name, then escalate to the programme officer
  - D. Ask the beneficiary to visit the district office in person
- Correct answer: C. Note the request with date and name, then escalate to the programme officer
- Guidance / explanation: This is a Right to Access request. The field worker should record the request and escalate it to the programme officer so the programme team can respond within the required timeline.

### Q6. Under DPDP, within how many days must the organisation respond to a beneficiary's rights request?

- Module: Module 3
- Topic: Response timeline
- Options:
  - A. 30 days
  - B. 60 days
  - C. 90 days
  - D. 180 days
- Correct answer: C. 90 days
- Guidance / explanation: Rule 14(3) of the DPDP Rules 2025 sets the maximum response time at 90 days for rights requests.

### Q7. A field implementor accidentally sends a spreadsheet with 30 beneficiary names and TB status to a WhatsApp group. What should happen?

- Module: Module 4
- Topic: Breach response
- Options:
  - A. Delete the message from WhatsApp and hope no one saw it
  - B. Wait and see if any harm occurs before reporting
  - C. Report it immediately to the supervisor and IT - this is a breach
  - D. Only report it if 100 or more people are affected
- Correct answer: C. Report it immediately to the supervisor and IT - this is a breach
- Guidance / explanation: This is a personal data breach because health data was disclosed through an insecure channel. It should be reported immediately.

### Q8. After a data breach is discovered, within how long must the organisation file a detailed report with the Data Protection Board of India?

- Module: Module 4
- Topic: 72-hour rule
- Options:
  - A. 24 hours
  - B. 48 hours
  - C. 72 hours
  - D. 7 working days
- Correct answer: C. 72 hours
- Guidance / explanation: Rule 7(2) of the DPDP Rules 2025 requires a detailed breach report to the DPBI within 72 hours.

### Q9. A field coordinator wants to photograph a 10-year-old child at a nutrition camp for use in a donor report. What is required before taking the photo?

- Module: Module 5
- Topic: Children's data
- Options:
  - A. The child's verbal permission is sufficient
  - B. No consent is needed - it is for a good cause
  - C. Photography consent plus verifiable parental or guardian consent
  - D. Approval from the programme officer alone
- Correct answer: C. Photography consent plus verifiable parental or guardian consent
- Guidance / explanation: An identifiable photo is personal data, and the child is a minor. For a donor report, photography consent and verifiable parental or guardian consent are required.

### Q10. What is the maximum financial penalty the organisation could face for failing to implement adequate data security safeguards?

- Module: Module 0
- Topic: Why it matters
- Options:
  - A. INR 10 crore
  - B. INR 50 crore
  - C. INR 100 crore
  - D. INR 250 crore
- Correct answer: D. INR 250 crore
- Guidance / explanation: Schedule Item 1 of the DPDP Act sets the maximum penalty for failure to implement adequate security safeguards at INR 250 crore.

### Q1. Which of the following is the best test for deciding whether something is personal data?

  - B. It is personal data only if it is health-related
  - C. It is personal data if an individual can be identified directly or indirectly
  - D. It is personal data only if it is stored digitally
- Correct answer: C. It is personal data if an individual can be identified directly or indirectly
- Guidance / explanation: Personal data includes any data about an identifiable individual, directly or in combination with other information.

### Q2. A field team collects name, village, phone number, and pregnancy status of women attending an ANC camp. What is the correct classification?

- Module: Module 1
- Topic: Classification
- Options:
  - A. Not personal data because it is program data
  - B. Personal data because individuals can be identified
  - C. Anonymous data because it is collected at a camp
  - D. Public data because many people attended the camp
- Correct answer: B. Personal data because individuals can be identified
- Guidance / explanation: Name, phone number, location, and pregnancy status can identify individuals and include health-related information.

### Q3. A beneficiary says, "I do not want to share my income, but I am okay answering other questions." What should the field staff do?

- Module: Module 2
- Topic: Specific refusal
- Options:
  - A. Mark income as zero

  - C. Respect the refusal and continue only with agreed questions
  - D. Stop the entire survey immediately
- Correct answer: C. Respect the refusal and continue only with agreed questions
- Guidance / explanation: Consent should be free and specific. The person can refuse a specific data point.

### Q4. Which of the following is the best example of invalid consent?

- Module: Module 2
- Topic: Invalid consent
- Options:
  - A. A beneficiary signs after the notice is explained in simple language
  - B. A beneficiary gives verbal consent, documented with witness details

  - D. A form says, "I agree to all future use of my data by the organisation"
- Correct answer: D. A form says, "I agree to all future use of my data by the organisation"

### Q5. A programme officer shares an Excel file containing beneficiary names, phone numbers, and TB status with the wrong external vendor by mistake. What is this?

  - C. A minor administrative mistake only
  - D. Not a breach because it was accidental
- Correct answer: B. A personal data breach that must be escalated immediately
- Guidance / explanation: Accidental disclosure of personal data is a breach and must be escalated.

### Q6. A dashboard shows very small village-level counts for a rare health condition. What is the main DPDP risk?

  - B. It may reveal or help identify specific individuals
  - C. It is not useful for leadership
  - D. It cannot be exported
- Correct answer: B. It may reveal or help identify specific individuals
- Guidance / explanation: Small counts can create re-identification risk, especially for rare conditions or small geographies.

### Q7. Which action is safest before sharing individual-level beneficiary data with an external partner?

- Module: Module 4
- Topic: External sharing safeguards
- Options:
  - A. Share it if the partner is well known
  - B. Share it if the data is needed urgently
  - C. Check consent or purpose coverage, data sharing agreement, minimisation, and legal or IT governance review
  - D. Remove names only and share the rest freely
- Correct answer: C. Check consent or purpose coverage, data sharing agreement, minimisation, and legal or IT governance review
- Guidance / explanation: Individual-level data sharing needs purpose coverage, safeguards, and proper agreements. Removing names alone may not anonymise the data.

### Q8. A field phone with offline ODK forms is stolen. The forms contain names, phone numbers, and health details. What should happen first?

  - D. Delete the ODK account next month
- Correct answer: B. Inform supervisor and IT immediately
- Guidance / explanation: Lost or stolen devices with personal data must be reported immediately so containment and breach assessment can begin.

### Q9. Which statement about children's data is most appropriate?

- Module: Module 5
- Topic: Children's data
- Options:
  - A. Children's data can be collected freely if the program is useful
  - B. Children's data never requires consent
  - C. Children's data generally needs parental or guardian consent unless a specific exemption applies
  - D. Children's data is not personal data
- Correct answer: C. Children's data generally needs parental or guardian consent unless a specific exemption applies
- Guidance / explanation: Children's data requires extra protection. Some healthcare or education-related exemptions may apply, but they should not be assumed casually.

### Q10. A BI analyst replaces beneficiary names with ID numbers before sharing a dataset. The ID numbers can still be linked back to names using another file. What is this?

- Module: Module 5
- Topic: Pseudonymisation

  - D. Aggregated data
- Correct answer: B. Pseudonymisation, and still likely personal data
- Guidance / explanation: If the person can be re-identified through a linking file, the dataset is not truly anonymised.
